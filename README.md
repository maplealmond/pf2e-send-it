# PF2e Send It

Sometimes you want to just hand your rogue the healing potion.

This module adds a "Send To" option to inventory items on PF2e character sheets. Items are routed through the party stash where only the sender and intended recipient can see them. The recipient can accept items when they next log on; the sender can cancel a pending send. If the recipient rejects, it bounces back as a reverse send that the original sender can accept or re-cancel.

No GM needs to be online. No socket relay runs between players. All transfers ride on the collective ownership of the Party actor.

## Usage

On any inventory row on a character sheet you own, click the paper-plane icon next to the carry-type controls. Pick a recipient from the party, choose a quantity, done.

The recipient will see a notification the next time they connect, listing any items waiting for them. They can accept, reject, or Accept All. In-session sends pop a toast; rapid-fire sends are batched into a single toast.

Pending items appear in the party stash with a ✓ (accept) button for the recipient and an ✗ (cancel) button for the sender. Other players don't see the row at all.
